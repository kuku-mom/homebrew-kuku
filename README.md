# Homebrew Kuku

This Homebrew tap is deprecated.

Kuku is now distributed through the official website:

https://www.kuku.mom/

## Download Kuku

Please download and install the latest version of Kuku from:

https://www.kuku.mom/

Future releases may not be published through this Homebrew tap.

## Legacy Homebrew Cask

The existing cask is kept for users who installed Kuku through Homebrew:

```sh
brew tap kuku-mom/kuku
brew install --cask kuku
```

This tap should be treated as legacy distribution. For the latest version and
recommended installation path, use the official website instead.

## Uninstall

If you installed Kuku through Homebrew and want to remove it:

```sh
brew uninstall --cask kuku
brew untap kuku-mom/kuku
```

If you want to remove local application data as well:

```sh
brew uninstall --zap --cask kuku
```
